📖 使用说明

一、64位二进制数转换器

用于查看和编辑一个 64bit 无符号整数的各种表示形式，适用于寄存器值的调试与分析。

  • 二进制位显示：64 位按 4 行 × 16 列排列，每 4bit 一组。点击任意 bit 可翻转该位（0↔1），三种进制表示自动同步更新。
  • 数值表示：十六进制、十进制、二进制三种格式，均可手动输入修改。输入后自动同步到其他两种格式及 bit 显示。
    • 十六进制：支持 0x 前缀或纯数字
    • 十进制：支持负数（自动转为 64 位补码）
    • 二进制：支持空格分隔，如 1010 0011 ...

二、移位运算

对当前 64 位数值进行移位操作，仅输出结果，不修改原值。

  • 逻辑移位：空位补 0
  • 算术移位：右移时高位补符号位（bit63），左移同逻辑移位
  • 循环移位：移出的位从另一端补回
  • 输入移位位数后，自动预览左移/右移结果（HEX/DEC/BIN 三种格式）
  • 点击方向按钮锁定显示该方向的结果，点击「↺ 重置」清除

三、域段提取

从 64 位数值中提取指定位段，支持同时存在多个域段。

  • 添加域段：点击「+ 添加域段」新增，点击「删除」移除
  • 命名：每个域段可输入自定义名称（如 opcode、addr）
  • 范围输入：格式为 高位:低位，如 20:16 表示提取 bit20 到 bit16
  • 域段移位：对提取出的域段值进行移位（逻辑/算术/循环），同样仅输出结果
  • 重置：点击「↺ 重置」清除移位结果并恢复默认位数

四、数据导出 / 导入

保存和恢复当前工作状态，方便分享和归档。

  • 导出 JSON：完整保存主数值、移位设置、所有域段（含名称）、计算历史，可重新导入恢复
  • 导出文本报告：生成可读的纯文本格式，适合粘贴到文档或邮件中
  • 导入 JSON：从 JSON 文件恢复所有状态
  • 复制到剪贴板：将 JSON 数据复制到剪贴板，便于快速分享

五、混合进制计算器

支持任意进制混合运算的表达式计算器。

  • 进制前缀： 0x 十六进制、0b 二进制、0d 十进制、无前缀默认十进制
  • 算术运算：+ - * / %，支持括号改变优先级
  • 移位运算：<< 左移、>> 右移
  • 按位运算：
    • & — AND（按位与）
    • | — OR（按位或）
    • ^ — XOR（按位异或）
    • ~ — NOT（按位取反，64 位）
  • 运算符优先级：（从高到低）~ → * / % → + - → << >> → & → ^ → |
  • 示例：
    • 0xFF & 0b1010 → 按位与
    • (0x100 - 1) >> 4 → 先减后右移
    • ~0x0F | 0b1010 → 取反后按位或
  • 结果同时显示二进制、十进制、十六进制三种格式，保留最近 10 条计算历史
