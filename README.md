# 🔧 数字芯片设计前端计算器

一个专为数字芯片设计前端工程师打造的在线计算器，支持 64 位二进制数的各种操作和转换。

🌐 **在线使用**: [https://celestial-42.github.io/chip_de_calculator/](https://celestial-42.github.io/chip_de_calculator/)

## ✨ 功能特性

### 1. 64位二进制数转换器
- **可配置位宽**: 支持 1~256 位动态调整
- **二进制位显示**: 点击任意 bit 可翻转该位（0↔1）
- **三种进制表示**: 十六进制、十进制、二进制，均可手动编辑
- **自动同步**: 修改任意一种表示，其他自动更新

### 2. 移位运算
- **逻辑移位**: 空位补 0
- **算术移位**: 右移时高位补符号位
- **循环移位**: 移出的位从另一端补回
- **仅输出结果**: 不修改原始数值

### 3. 域段提取
- **多域段支持**: 可同时提取多个位段
- **域段命名**: 为每个域段添加自定义名称
- **域段移位**: 对提取的域段值进行独立移位
- **范围格式**: `高位:低位`（如 `20:16`）

### 4. 数据导出/导入
- 📥 **导出 JSON**: 完整保存所有状态，可重新导入
- 📄 **导出文本报告**: 生成可读的纯文本格式
- 📂 **导入 JSON**: 从文件恢复工作状态
- 📋 **复制到剪贴板**: 快速分享数据

### 5. 混合进制计算器
- **多进制混合**: 支持 `0x`（十六进制）、`0b`（二进制）、`0d`（十进制）前缀
- **算术运算**: `+ - * / %`
- **移位运算**: `<< >>`
- **按位运算**: `& | ^ ~`
- **运算符优先级**: 自动处理
- **历史记录**: 保留最近 10 条计算

## 🚀 使用方法

### 在线使用
直接访问 [GitHub Pages](https://celestial-42.github.io/chip_de_calculator/) 即可使用，无需安装。

### 本地运行
1. 克隆仓库
   ```bash
   git clone https://github.com/Celestial-42/chip_de_calculator.git
   cd chip_de_calculator
   ```

2. 用浏览器打开 `index.html`
   ```bash
   open index.html  # macOS
   # 或双击 index.html 文件
   ```

## 💡 使用场景

- **寄存器调试**: 查看和修改寄存器各位的值
- **协议分析**: 提取数据帧中的各个字段
- **位运算验证**: 快速验证按位运算结果
- **进制转换**: 在十六进制、十进制、二进制之间快速转换

## 📝 示例

### 二进制位操作
```
输入: 0x00000000000000FF
点击 bit 0 → 变为 0x00000000000000FE
```

### 域段提取
```
主数值: 0x123456789ABCDEF0
域段 20:16 → 提取 bit20~bit16 → 0x15
```

### 混合进制计算
```
表达式: 0xFF & 0b1010 | 0x1A ^ ~0x0F
结果: HEX 0xF5, DEC 245, BIN 1111 0101
```
